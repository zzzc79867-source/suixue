# 随学 · 碎片化学习

一个为自己做的期末复习 + 四级备考 PWA。手机浏览器打开后「添加到主屏幕」即可像 App 一样用，支持离线、进度本地保存。

## 学习方式

- 首页只有一个「每日打卡区 + 开始学习」入口，不按学科分入口
- 点「开始学习」后，系统按 **权重 × 考试倒计时** 自动分配今日卡片
- 学习流程遵循「上课」理念：一屏一卡，先学新课概念，再点击核对解答，最后进入练习与复习
- 公式使用本地 KaTeX 排版，按教材习惯显示分数、上下标和符号
- 间隔重复复习（1→2→4→7→15 天记忆箱）保证学过的内容按期回炉
- 单词支持 TTS 朗读、「认识即跳过」自测筛选，首页有学习热力图

## 功能板块

- **学习（首页）**：打卡状态、今日任务量、唯一「开始学习」按钮、最近考试倒计时、今日课表（只读）
- **刷题页**：三种卡片 —— 新课概念卡（教学）、复习概念卡（先回忆再核对）、单词卡（翻转 + 滑动）、选择题卡（作答 + 解析）
- **计划**：各科未学/到期复习/每日新课/已掌握统计；可调「权重」「每日新卡上限」「每日新课倍速」「单词范围（只学高频前 N 词）」「章节范围（如物理化学只学前 6 章=上册）」
- **导入**：底部独立入口。电脑端放 JSON 进 content/ 重新部署，或手机直接上传 JSON 导入本机
- **我的**：学习数据、进度导出/导入备份、清空进度

## 已内置内容

- **四级英语**：4544 个大纲词（按真题考频从高到低排列，分高频/中频/低频三段），另含听力、阅读、翻译、写作四块的题型与方法讲义卡片
- **物理化学（天大版）**：12 章 102 张细分卡（上册第 1–6 章为主，概念、例题与快检题混排）
- **电工电子技术（电子工业出版社版）**：7 模块 84 张细分卡（概念、例题与判断/选择题混排）

## 卡片格式（三种类型）

```json
{ "id": "x1", "type": "concept", "title": "知识点", "body": "- 要点一\n- 要点二", "tag": "第一章" }
{ "id": "x2", "type": "question", "stem": "1+1=?", "options": ["1","2","3","4"], "answer": 1, "explanation": "1+1=2" }
{ "id": "x3", "type": "word", "front": "example", "back": "n. 例子", "phonetic": "/ɪɡˈzɑːmpl/", "example": "This is an example.", "exampleZh": "这是一个例子。" }
```

## 本地运行

```bash
node tools/serve.mjs     # 或 npm run dev
# 打开 http://localhost:4173
```

手机真机调试：手机和电脑连同一 WiFi，把 localhost 换成电脑的局域网 IP。

## 部署（免费公开网址）

- **Vercel**：推到 GitHub 后到 vercel.com 导入仓库（自动识别静态站）
- **GitHub Pages**：推送到 GitHub，Settings → Pages → 选分支根目录

### 上线检查清单

- [ ] `npm run check` 通过（内容结构与计划引擎校验）
- [ ] 改了内容或代码后，把 `sw.js` 里的 `CACHE` 版本号 +1，否则手机端拿不到更新
- [ ] 手机打开网址 →「添加到主屏幕」，确认图标与离线可用
- [ ] 在「我的」里导出一次备份，确认恢复流程可用

## 目录结构

```
study-app/
├─ index.html / manifest.webmanifest / sw.js
├─ css/style.css
├─ js/            main(路由) · store(进度/权重/导入) · srs(间隔重复) · planning(计划队列) · content(加载) · ui(工具) · views/
├─ content/       index.json + subjects/*.json（学习内容，与程序解耦）
├─ icons/
└─ tools/serve.mjs
```
